# Projeto de prática dos conteúdos das aulas

Curso de React e Nextjs, consumimos uma api do jsonplaceholder, onde renderizamos em tela posts e 'imagens'.
Usamos componentes de classe, metodos de ciclo de vida do componente, e arrow functions.

Com o curso eu aprendi muitas coisas novas, e aprimorei muito minha lógica na hora de fazer componentes... como por exemplo, separa-los e organiza-los, se preciso que o componente se repita em um outro canto da página, o melhor é separa-lo em um componente e reutiliza-lo.

Mexer com componente de classe ao invez de componentes funcionais me deu entendimento sobre hooks, hoje sei a importancia de aprender sobre o ciclo de vida de um componente.
